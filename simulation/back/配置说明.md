# 智能面试系统配置说明

## 环境变量配置

请在 `simulation/back` 目录下创建 `.env` 文件，并配置以下环境变量：

```env
# 星火大模型HTTP API配置
SPARK_API_URL=https://spark-api-open.xf-yun.com/v1/chat/completions
SPARK_API_PASSWORD=your_spark_api_password_here
SPARK_MODEL=SPARK MAX

# 语音合成API配置
# 从讯飞开放平台获取：https://console.xfyun.cn/app/myapp
TTS_APP_ID=your_tts_app_id_here
TTS_API_KEY=your_tts_api_key_here
TTS_API_SECRET=your_tts_api_secret_here
TTS_REQUEST_URL=wss://cbm01.cn-huabei-1.xf-yun.com/v1/private/mcd9m97e6

# 语音识别API配置
# 从讯飞开放平台获取：https://console.xfyun.cn/app/myapp
ASR_APP_ID=your_asr_app_id_here
ASR_API_KEY=your_asr_api_key_here
ASR_API_SECRET=your_asr_api_secret_here
ASR_REQUEST_URL=ws://iat.xf-yun.com/v1
```

## 配置步骤

### 1. 星火大模型配置

1. 访问 [星火大模型控制台](https://console.xfyun.cn/services/bmx1)
2. 获取API密钥
3. 将密钥替换 `your_spark_api_password_here`

### 2. 语音合成API配置

1. 访问 [讯飞开放平台](https://console.xfyun.cn/app/myapp)
2. 创建应用或使用现有应用
3. 开通语音合成服务
4. 获取以下信息：
   - `APPID` → 替换 `your_tts_app_id_here`
   - `APIKey` → 替换 `your_tts_api_key_here`
   - `APISecret` → 替换 `your_tts_api_secret_here`

### 3. 语音识别API配置

1. 访问 [讯飞开放平台](https://console.xfyun.cn/app/myapp)
2. 使用同一个应用（或创建新应用）
3. 开通语音听写（流式版）服务
4. 获取以下信息（可与TTS使用相同的应用密钥）：
   - `APPID` → 替换 `your_asr_app_id_here`
   - `APIKey` → 替换 `your_asr_api_key_here`
   - `APISecret` → 替换 `your_asr_api_secret_here`

## 功能说明

### 语音合成功能

- ✅ 支持将面试官的问题转换为语音
- ✅ 动态语音播放动画
- ✅ 自动播放语音（延迟1秒）
- ✅ 智能跳过欢迎消息
- ✅ 错误处理和状态提示

### 语音识别功能

- ✅ 支持录音输入回答面试问题
- ✅ 实时录音状态显示和计时
- ✅ 语音转文字识别
- ✅ 识别结果预览和编辑
- ✅ 支持文字/语音输入模式切换

### 使用方式

#### 语音合成（面试官）
1. 面试官发送问题后，等待1秒自动开始语音合成
2. 显示"正在生成语音..."状态和动画
3. 自动播放语音，显示"正在播放语音..."状态
4. 播放完成后自动停止

#### 语音识别（求职者）
1. 点击🎤按钮切换到语音输入模式
2. 点击"🎤 开始录音"按钮开始录音
3. 录音过程中显示实时计时和动画
4. 点击"⏹️ 停止录音"完成录音
5. 自动进行语音识别，显示识别结果
6. 确认后点击"📤 发送"提交回答

### 注意事项

#### 语音合成
- 语音合成服务需要网络连接
- 单次合成文本长度限制为500字符
- 如果TTS服务不可用，会显示相应提示
- 音频格式为MP3，采样率24kHz

#### 语音识别
- 语音识别服务需要网络连接
- 需要浏览器麦克风权限
- 建议在安静环境下录音
- 支持中文普通话识别
- 录音格式为WebM，采样率16kHz
- 识别结果可预览和编辑后发送

## 故障排除

### 常见问题

1. **语音合成失败**
   - 检查网络连接
   - 确认TTS API密钥配置正确
   - 检查API服务状态

2. **音频播放失败**
   - 检查浏览器音频权限
   - 确认音频格式支持
   - 检查设备音量设置

3. **语音识别失败**
   - 检查网络连接
   - 确认ASR API密钥配置正确
   - 检查麦克风权限设置
   - 确认录音环境较为安静

4. **录音功能异常**
   - 检查浏览器麦克风权限
   - 确认使用HTTPS或localhost访问
   - 检查设备麦克风是否正常
   - 尝试刷新页面重新授权

5. **API配置错误**
   - 确认.env文件位置正确
   - 检查环境变量格式
   - 重启后端服务
   - 确认TTS和ASR使用相同或不同的应用ID

### 调试信息

后端启动时会显示以下状态信息：
- ✅ 星火大模型HTTP API配置成功
- ✅ 语音合成API配置成功
- ✅ 语音识别API配置成功

前端控制台会显示以下调试信息：
- 🎤 录音相关：开始录音、停止录音、文件大小等
- 🔊 语音合成：自动播放、生成状态等  
- 📡 API调用：请求状态、响应结果等

如果显示警告信息，请检查对应的配置项。
