# 智能面试系统启动指南

## 问题诊断与解决

### 常见问题
1. **后端服务未启动** - 前端会显示网络连接错误
2. **依赖未安装** - 命令执行失败
3. **端口被占用** - 服务无法启动

## 启动步骤

### 方法一：使用自动启动脚本（推荐）
```bash
# 双击根目录下的 start_dev.bat 文件
```

### 方法二：手动启动

#### 1. 启动后端服务
```bash
cd simulation/back
# 安装依赖（首次运行）
pip install -r requirements.txt
# 启动服务
python app.py
```

#### 2. 启动前端服务
```bash
cd simulation/FrontEnd
# 安装依赖（首次运行）
npm install
# 启动开发服务器（支持网络访问）
npm run dev -- --host
```

## 访问地址
- **前端应用**: http://localhost:5174
- **后端API**: http://localhost:5000
- **健康检查**: http://localhost:5000/api/health

## 网络访问
前端服务配置为在所有网络接口上运行，您可以通过以下方式访问：
- **本地访问**: http://localhost:5174
- **局域网访问**: http://[您的IP地址]:5174
- 例如：http://192.168.1.100:5174

## 新功能：语音合成

### 功能说明
- ✅ 面试官问题自动转换为语音并播放
- ✅ 动态语音播放动画
- ✅ 支持语音录入回答问题
- ✅ 实时录音状态和语音识别
- ✅ 智能错误处理

### 配置要求
1. **配置API密钥**: 在 `simulation/back/.env` 文件中配置TTS和ASR相关信息
2. **安装依赖**: 确保安装了 `websocket-client` 库
3. **网络连接**: 语音合成和识别需要稳定的网络连接
4. **浏览器权限**: 语音识别需要麦克风权限

详细配置请参考：`simulation/back/配置说明.md`

### 使用方式
#### 语音合成（自动）
1. 面试官发送问题后，自动开始语音合成和播放
2. 支持播放状态指示和错误提示

#### 语音识别（手动）
1. 点击🎤按钮切换到语音输入模式
2. 录音回答面试问题
3. 自动识别并转换为文字
4. 确认后发送回答

## 故障排除
1. **端口被占用**: 检查5000和5174端口是否被其他应用占用
2. **依赖缺失**: 确保已安装Node.js和Python，以及websocket-client库
3. **API密钥**: 检查星火大模型和语音合成API密钥是否正确配置
4. **网络问题**: 确保防火墙允许5174和5000端口访问
5. **代理配置**: 前端通过Vite代理访问后端API，无需额外配置
6. **端口自动切换**: 如果配置端口被占用，Vite会自动选择下一个可用端口
7. **语音合成问题**: 检查TTS API配置和网络连接状态
8. **语音识别问题**: 检查ASR API配置、麦克风权限和网络连接状态
